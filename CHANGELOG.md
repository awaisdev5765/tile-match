# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-05-19

### Changed
- **Open Source Transition**: Ported from the commercial Play Store version to a fully Free and Open Source Software (FOSS) release.
- **License Change**: Code relicensed under **GNU GPLv3**; Assets updated to **CC0 1.0 Universal** (Public Domain).
- **Privacy & Ads**: Removed all advertising SDKs, analytics trackers, and third-party dependencies.
- **Dependencies**: Cleaned up build configuration to remove proprietary libraries.

### Added
- Full source code availability for community review and modification.
- `LICENSE` file containing GPLv3 and CC0 terms.
- `CHANGELOG.md` for version tracking.

### Notes
- This version is identical in gameplay to the previous commercial release but runs entirely offline without tracking.
- Compatible with F-Droid repository standards.
